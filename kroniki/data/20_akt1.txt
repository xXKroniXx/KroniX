as menel
if MENEL_KIELICH po
"Pieniążek dla kaleki? Kulawy Józek wszystko widzi, wszystko słyszy..."
menu
 opt "Co wiesz o dokach? [5$]" doki ifgold 5
 opt "Masz kielich z kościoła?" kielich if KIELICH_Q
 opt "Spadaj." pa
endmenu
:doki
cash -5
"Magazyn numer siedem. Tam trzymają najcenniejsze rzeczy. Pilnuje go {y}Wielki Paddy{-} — łapami łamie ludziom kręgosłupy."
"A w nocy, przy browarze O'Malleya, zawsze pali się światło. Coś tam się dzieje."
end
:kielich
"K-kielich? Jaki kielich? Ja nic..."
menu
 opt "Odkupię go. [20$]" kup ifgold 20
 opt "Oddawaj albo połamię ci drugą nogę. [Szacunek 2]" grozi ifge SZACUNEK 2
 opt "Zostaw, nieważne." pa
endmenu
:kup
cash -20
goto daj
:grozi
add HONOR -1
"Dobrze już, dobrze! Nie bij kaleki!"
:daj
set MENEL_KIELICH
give kielich
"Masz, masz. Ja tylko... zimno było, chciałem sprzedać Feliksowi."
quest kielich "Odzyskałeś kielich mszalny. Odnieś go ojcu Stanisławowi do kościoła."
end
:po
"Józek nic nie widział, Józek nic nie wie."
end
:pa
"Niech cię szczury zjedzą..."

# ------------------------------------------------------------ fotograf
@script s_rubin
as rubin
if ZDJECIA_DANE po
ifhas aparat oddaj
if RUBIN_1 czeka
set RUBIN_1
"Zamknięte! Nie... ty jesteś Kroniewski? Brat Janka?"
"Wejdź. Szybko. Zamknij drzwi."
"Janek przyniósł mi {y}film{-} do wywołania. Zrobił zdjęcia nocą w dokach. To, co na nich jest... Boże."
"Wczoraj przyszli ludzie O'Malleya. Rozbili mi pracownię i zabrali mój {y}aparat{-}. Szukali filmu."
"Zdjęcia schowałem. Ale bez aparatu nie mam z czego żyć. Odzyskaj go — ponoć trzymają łupy w {y}zaułku{-} na zachód od tylnej ulicy — a oddam ci odbitki."
quest rubin "Ludzie O'Malleya ukradli aparat Rubina. Szukaj go w zaułku (tylna ulica, na zachód)."
end
:czeka
"Masz mój aparat? Zaułek, na zachodzie. Uważaj na siebie."
end
:oddaj
take aparat
set ZDJECIA_DANE
add HONOR 1
xp 50
"Mój Graflex! Jesteś aniołem, Kroniewski."
"Masz. Obiecałem. {y}Zdjęcia z doków{-}."
give zdjecia
as -
"Rozmazane, nocne zdjęcia. Nabrzeże. Człowiek leży twarzą w wodzie. Nad nim stoi mężczyzna w mundurze z galonami kapitana."
as tomek
"{r}Doyle.{-} To kapitan Doyle. A ten na ziemi..."
as rubin
"...to Staszek Kowalik. Ten ze związku. Janek to widział. I sfotografował."
"Z tym możesz iść tylko do kogoś uczciwego. Jeśli w tym mieście jeszcze ktoś taki jest."
done rubin
quest dowody "Masz zdjęcia: kapitan Doyle nad ciałem Kowalika. Uczciwy glina mógłby coś z tym zrobić."
end
:po
"Uważaj na te zdjęcia. Dla nich warto zabić."

@script s_mickey
as mickey
if BOKS_DONE po
"Tomek Kroniewski! Pamiętam cię z ringu, zanim zamknęli halę na Division. Miałeś lewy prosty jak młot."
"Mam walkę w sobotę. Mój zawodnik złamał rękę. Przeciwnik: {y}Irlandzki Byk{-}, pupilek O'Malleya."
"Wygrana: {y}150 dolców{-}. Wchodzisz?"
menu
 opt "Wchodzę. Walczę uczciwie." walcz
 opt "(Położę się w trzeciej rundzie — umowa z Vitem.)" rzuc if BOKS_USTAWKA
 opt "Jeszcze nie teraz." nie
endmenu
:walcz
"Tak trzymaj! Do narożnika!"
fade out
fade in
as bokser
"Polaczek? Zjem cię na śniadanie!"
battle bokser bg=ring lose=przegral
set BOKS_DONE
set BOKS_WYGRANA
as mickey
"Na deski! BYK LEŻY! Kroniewski wygrywa!"
cash 150
add SZACUNEK 2
add HONOR 1
if BOKS_USTAWKA vito_zly
end
:vito_zly
add MORETTI -1
toast "Vito Russo nie będzie zadowolony..."
end
:przegral
set BOKS_DONE
as mickey
"Leżysz, synku. Ale walczyłeś jak lew. Masz, 20 dolców za odwagę."
cash 20
add SZACUNEK 1
end
:rzuc
fade out
as -
"Trzecia runda. Byk trafia cię w szczękę, choć mógłbyś zrobić unik. Padasz. Sędzia liczy do dziesięciu."
"Z trybun słychać gwizdy. W pierwszym rzędzie Vito Russo uśmiecha się i liczy pieniądze."
fade in
set BOKS_DONE
set BOKS_RZUCONA
cash 250
add HONOR -2
add MORETTI 1
as mickey
"Coś ty zrobił, Tomek? Widziałem ten cios. Mogłeś go uniknąć."
"Wynoś się z mojej sali."
end
:nie
"Namyśl się. Taka szansa nie trafia się dwa razy."
end
:po
if BOKS_RZUCONA wstyd
"Mistrzu! Pamiętam twój lewy prosty w tej walce. Byk dalej nosi śliwę pod okiem!"
end
:wstyd
"Nie mam ci nic do powiedzenia, Kroniewski."
